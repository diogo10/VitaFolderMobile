## Full changelog

### Reminders

- **The notification small icon now survives release shrinking.** Flutter's
  Gradle plugin enables R8 resource shrinking for release builds, so
  `ic_notification` (referenced only by name from Dart) was stripped from the
  AAB and `initialize()` failed with `invalid_icon` — no reminder ever showed
  a notification. Kept with `tools:keep` in
  `android/app/src/main/res/raw/keep.xml`, guarded in
  `test/android_manifest_test.dart` (`6cc0e95`).
  Verified in the real release AAB of this build.
- **Backend hiccups no longer crash reminders or notes.**
  `GetProfilesWithRoleForFamily` throws on a 504, and the exception escaped the
  `Either.fold` async callback; both `GetReminderUsecase` and
  `GetNotesUsecase` now return `Left(Failure(...))` and the screens show their
  error state (`7ae0c5f`).
- **Notification settings open without crashing.** GetIt keys by exact type;
  the reminder notification service was registered only as
  `IReminderNotificationService` while the route asks for the core
  `NotificationSender`. Registered under both types, with a locator test
  (`99dd93d`).

### Account & invites

- **Invite failures show localized copy.** A failed `resend-email-v1` call
  exposed the raw `FunctionException` in the UI; every edge throw now maps to
  the localized `sendFailed` message, with the stack trace kept for
  Crashlytics (`dfb97e6`).

### Billing

- **Billing fails closed on a rejected key.** An invalid RevenueCat key made
  `isPro` re-fetch on every lookup and record a handled non-fatal each time.
  The service now disables billing for the session on unrecoverable errors,
  logs one breadcrumb without the error object, and short-circuits
  `isPro`/`getOfferingPrices` (`9df1134`).

### Build

- **AGP 9.0.1 + Gradle 9.1.0**, which turns on optimized resource shrinking
  inside R8 (the Play Console DEX optimization report asked for it).
  `android.newDsl=false` and `android.builtInKotlin=false` because the Flutter
  Gradle plugin still needs the legacy DSL and the app applies
  `kotlin-android`. `isMinifyEnabled`/`isShrinkResources` declared explicitly;
  `android/app/proguard-rules.pro` added; google-services 4.5.0 (`28eaa2a`).

## Notes

- Internal track only. Anyone on the internal testing list runs code that
  1.0.5 users never saw.
- This build **shipped with billing disabled**: `build_aab_release.yml` does
  not pass `REVENUECAT_GOOGLE_API_KEY`, so `SubscriptionService.initialize`
  skips configuration and `isBillingAvailable` is `false`. Same gap in
  `build_apk.yml`. See the 1.0.7 notes.
- `ic_notification.xml` is present in the release AAB and `keep.xml` is not
  packaged (aapt2 reads it at build time), confirmed with `unzip -l`.
